# Deploying Skill Sync to Render

This guide provides step-by-step instructions for deploying the Skill Sync application (Angular frontend and Django backend) to Render.

## Prerequisites

1. A [Render](https://render.com/) account
2. Your project code pushed to a GitHub repository

## Deployment Steps

### 1. Connect Your GitHub Repository to Render

1. Log in to your Render account
2. Click on "New" and select "Blueprint" from the dropdown menu
3. Connect your GitHub account if you haven't already
4. Select the repository containing your Skill Sync project
5. Click "Apply Blueprint"

Render will automatically detect the `render.yaml` file in your repository and create the services defined in it.

### 2. Configure Environment Variables

The `render.yaml` blueprint marks `RAPIDAPI_KEY` as `sync: false` — set it in
the Render dashboard (Environment tab), never in the file. Required backend
variables in production:

- `SECRET_KEY` (auto-generated by Render)
- `DEBUG=False`
- `ALLOWED_HOSTS=skill-sync-backend.onrender.com`
- `CORS_ALLOWED_ORIGINS=https://skill-sync-frontend.onrender.com`
- `RAPIDAPI_KEY` (optional — without it the app uses the local dataset)

**Rotate any API key that was ever committed to git.** Earlier versions of
this repository contained a live RapidAPI key in code — revoke it in your
RapidAPI dashboard and use a fresh one only via environment variables.

### 3. Monitor Deployment

1. Render will automatically build and deploy your services
2. You can monitor the build and deployment process in the "Events" tab
3. Once deployment is complete, you can access your application using the provided URLs

### 4. Database Considerations

This deployment uses SQLite, which is suitable for academic showcase purposes. For a production application with multiple users, consider migrating to PostgreSQL, which is better supported by Render.

### 5. Troubleshooting

If you encounter any issues during deployment:

1. Check the build logs in the "Events" tab
2. Ensure all required environment variables are set
3. Verify that the `build.sh` script has execute permissions
4. Check that the paths in `render.yaml` match your project structure

## Post-Deployment

After successful deployment:

1. Test all features of your application
2. Update the frontend environment.prod.ts file if the backend URL changes
3. Set up monitoring and logging as needed

## Manual Deployment (Alternative)

You do not need the Blueprint feature. Create the services manually —
or mix and match hosts (for example Render backend + Netlify frontend).

### Backend on Render (manual)

1. In Render, create a new Web Service and connect your GitHub repository
2. Configure the service:
   - Name: skill-sync-backend
   - Runtime: Python
   - Build Command: `cd pythonmodel && chmod +x build.sh && ./build.sh`
   - Start Command: `cd pythonmodel && gunicorn job_api.wsgi:application`
3. Add the environment variables listed above (SECRET_KEY, DEBUG=False,
   ALLOWED_HOSTS, CORS_ALLOWED_ORIGINS, RAPIDAPI_KEY)
4. Click "Create Web Service"

Note: without `RAPIDAPI_KEY` the backend still works — job search falls back
to TF-IDF matching over the bundled `Job_listings.csv` dataset.

### Frontend option A — any static host (Netlify / Vercel / GitHub Pages)

The frontend is a plain static SPA after `npm run build`; the output folder is
`pythonmodel/job-portal-frontend/dist/job-portal-frontend/browser`.

1. Point `environment.prod.ts`'s `apiUrl` at your backend URL, then rebuild:
   ```bash
   cd pythonmodel/job-portal-frontend
   npm install && npm run build
   ```
2. Deploy that `browser` folder:
   - **Netlify**: drag-and-drop the folder, or connect the repo
     (the included `public/_redirects` handles SPA routing)
   - **Vercel**: connect the repo (the included `vercel.json` handles routing)
   - **GitHub Pages**: publish the folder as a static site

### Frontend option B — Render Node service (manual)

1. Create a new Web Service (runtime: Node) from the same repository
2. Configure:
   - Name: skill-sync-frontend
   - Build Command: `cd pythonmodel/job-portal-frontend && npm install && npm run build`
   - Start Command: `cd pythonmodel/job-portal-frontend && npm run serve:spa`
3. Click "Create Web Service"
